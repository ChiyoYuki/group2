# 丹噶尔古城项目素材

来源：用户提供的 `丹噶尔古城项目_简笔画图文配音完整包.zip`；ZIP 内根目录名为
`丹噶尔古城项目_图文配音素材包`。登记数据集为 `dangar-old-town`，数据版本 1。

清单 `project.json` 包含 4 张图片、10 段 AI 配音、1 份 Markdown 发现卡、3 份 CSV 表格，
共 18 个资源。原始文件放在 `backend/media/dangar-old-town/`，与苗族数据集分目录保存。
十段配音总长 183.552 秒；图、文、声按包内对应表配对，配音 02—08 对应七个过程步骤。

- 开场 PNG 为包内已生成的 AI 插画，作为问题引入，不是历史场景复原。
- 三张照片原样保留，包括已有水印；不推断摄影者、学生身份或具体活动日期。
- `discovery-card.md` 为本次整理的展示成果，不声称收到既有学生作品照片。
- `comparison.csv` 保留现代服务区与古城功能的比较，作为第六步附件。
- `knowledge-status.csv` 保留“资料支持”“一般常识”“未确认”“现代类比”等状态，作为第五步附件。
- `text-sources.csv` 保留 S01—S03 的题名、机构、网址与支持内容，作为来源段落附件。

原包文档仅作数据处理。来源声明和“喂马具体地点尚未确认”等事实边界保留，不把类比改写为历史名称。
说明与事实表不混入配音逐字台词，配音也不标为真实学生录音。

重新导入：

```bash
cd backend
uv run --no-sync python -m examples.import_packages --dataset dangar-old-town
```

从原 ZIP 重新整理时在命令后加 `--archive ../丹噶尔古城项目_简笔画图文配音完整包.zip`。
原文件大小、SHA-256、正文与 CSV 结构在写库前核对；相同修订重复导入会跳过。
